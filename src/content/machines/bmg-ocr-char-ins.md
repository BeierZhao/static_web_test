## Product Overview
The BMG-VISION OCR Character Inspection Machine uses OCR and machine vision technology to identify and inspect characters, numbers, and symbols on packaging surfaces through image processing and analysis.

## Features
- OCR-based character and symbol inspection
- Supports date, batch number, barcode, and QR code detection
- Automatic pass and fail judgment output
- Suitable for food, packaging, pharmaceutical, and cosmetic industries
